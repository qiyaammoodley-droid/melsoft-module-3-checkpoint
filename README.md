## About

This is my Module 3 JavaScript checkpoint project. I worked through the
operator topics and then used them in examples involving forms, permissions,
banking calculations and user interaction.

## Files

- `yourfirstname-yourlastname-module3.js` - Challenges 1-7, 9 and 10
- `challenge8.html` - Challenge 8

## Topics

The project covers arithmetic, assignment, comparison, logical, unary,
ternary, bitwise and special JavaScript operators. It also covers operator
precedence, equality, short-circuiting, browser prompts and debugging.

## Running the JavaScript

You can run the main file with Node:

```bash
node yourfirstname-yourlastname-module3.js
```

Challenge 8 needs to be opened in a web browser because it uses
`window.alert()`, `window.prompt()` and `window.confirm()`.
